# Bundled font

The PDF build embeds Noto Sans Regular, Italic, Bold, and Bold Italic so layout and glyph coverage do not depend on fonts installed on the build machine.

Noto fonts are published under the SIL Open Font License 1.1. The complete,
unmodified license text and Noto copyright notice are centrally stored in
[LICENSES/OFL-1.1.md](../../LICENSES/OFL-1.1.md). The repository's
[third-party license index](../../LICENSES/README.md) explains the distinction
from the MIT-licensed build tooling. Project information:
<https://notofonts.github.io/>.
