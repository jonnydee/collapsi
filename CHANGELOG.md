# Changelog

All notable changes to this unofficial Collapsi rules collection are documented here. Version numbers and edition names refer only to this repository, not to official Collapsi releases.

## 1.0.1 - 2026-08-16 - Collapsi Revival Edition

- Added Mark S. Ball's updated Jack setup for the standard 2-player game in all four languages.
- Clarified that the optional Revival Variations continue to use the Joker setup and its choice of a 1-, 2-, 3-, or 4-space opening move.
- Documented that compatible patch releases retain their edition name, while releases that add new variants receive a new edition name.

## 1.0.0 - 2026-08-15 - Collapsi Revival Edition

- Established English, German, French, and Spanish rulebooks.
- Documented the unofficial Joker Edition and optional Revival Variations.
- Recorded Collapsi v1.3.1 as the original reference and its explicit demonetization, free-to-play, credit, and linking requirements.
- Added multilingual navigation, licensing, attribution, and reproducible PDF builds.
