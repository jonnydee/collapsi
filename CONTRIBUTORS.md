# Contributors and creative roles

This file records creative roles that are not always obvious from Git history. It does not change ownership or license terms.

## Original game designer

- **Mark S. Ball** — inventor and designer of Collapsi; [official game page](https://riffleshuffleandroll.itch.io/collapsi). Mark is credited as the original designer, not represented as a contributor to this repository.

## Revival edition

- **Johann Duscher (a.k.a. Jonny Dee)** — originator of the Revival concept and Revival Variations; repository maintainer and editor.

## Translators

Future translators should be listed here with the language or locale they contributed. Do not infer authorship from a GitHub username; add a name only with the contributor's agreement.

## Technical contributors

Future build, design, accessibility, and tooling contributors may be listed here when their first contribution is accepted. Git history remains the detailed contribution record.
